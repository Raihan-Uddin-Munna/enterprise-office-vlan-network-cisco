Enterprise Office VLAN Network — Cisco Packet Tracer

A company-based Cisco networking project designed to demonstrate practical VLAN segmentation, trunking, inter-VLAN routing, network management, voice networking, Layer 2 security, and structured troubleshooting.

Project Overview

This project simulates the network of a small-to-medium enterprise office.

The company has separate departments, servers, IP phones, guest users, and network management devices. VLANs are used to logically separate these departments while controlled Layer 3 routing and security policies determine which networks can communicate.

The project was built in Cisco Packet Tracer.

Business Scenario

The simulated company, MunnaTech Solutions Ltd., requires a structured LAN where:

Departments are separated into dedicated VLANs.
Multiple switches can transport VLAN traffic through trunk links.
Different VLANs can communicate through Layer 3 routing.
Servers are isolated in a dedicated server VLAN.
Network devices use a separate management VLAN.
IP phones use a dedicated voice VLAN.
Guest users are separated from internal business networks.
Unused switch ports are secured.
Access ports use basic Layer 2 security.
Network failures can be identified and resolved using a structured troubleshooting process.
